メッセージ文言は実装（`lib/view/`）の文字列をそのまま記載しています。

## 2. 共通仕様

| 項目 | 仕様 |
| --- | --- |
| 遷移 | `Navigator` の `push` / `pushReplacement` / `popUntil`。名前付きルートは使わない |
| 単語カード | `ProductCard` を共通で使う。タップで単語詳細（SC-03）、長押しで操作メニュー（SC-05） |
| 広告 | 主要画面の下部にバナー。テスト終了・記事を開く・キャッシュクリアの前にインタースティシャル（3 分間隔） |
| テーマ | ライト / ダーク / 端末設定に追従。配色はテーマの色から取り、ダークモードでも判読できること |
| 読み込み中・エラー | 同梱データの読み込み中はインジケーター、失敗時はエラー文を表示 |

## 3. 画面定義

### SC-01 単語検索（ホーム）

| 項目 | 定義 |
| --- | --- |
| 目的 | 単語を名前・読みガナから検索し、説明を確認する |
| 表示項目 | 検索欄、検索結果のリスト、右上のメニューボタン、下部のバナー広告 |
| 初期表示 | 検索欄が空のとき、収録単語とカスタム単語から無作為に 15 件 |
| 検索条件 | 単語名または読みガナへの部分一致（大文字小文字を区別しない）。入力から 250ms 後に絞り込む |
| メッセージ | 該当なし:「一致する単語がありません」 |
| 操作 → 遷移 | 単語をタップ → 検索履歴に追加して SC-03 / 長押し → SC-05 / メニューボタン → SC-02 |

### SC-02 メニュー

| 項目 | 定義 |
| --- | --- |
| 表示項目 | 単語マイリスト / 単語テスト / 単語チェック問題 / 仕訳問題 / スケジュール管理 / 簿記ニュース / 設定 |
| 遷移 | 順に SC-10 / SC-20 / SC-22 / SC-24 / SC-30 / SC-40 / SC-50 |

### SC-03 単語詳細 / SC-04 メモ入力

| 項目 | 定義 |
| --- | --- |
| 表示項目 | 単語名、説明、保存済みのメモ、共有ボタン、メモを書くボタン |
| 共有 | ダイアログを画像にして OS の共有シートを開く |
| メモ保存 | 前後の空白を除いて保存し、「メモが保存されました」を表示。ダイアログ内のメモ表示も更新する |

### SC-05 単語の操作メニュー / SC-06 リストへの割り当て

| 項目 | 定義 |
| --- | --- |
| SC-05 の項目 | 「保存する」（→ SC-06）、「単語チェック問題に登録する」。表示する画面によって並び替え・削除が加わる |
| SC-06 の表示 | 全リストのチェックボックス（現在の所属を反映）、「保存単語一覧」のチェックボックス（初期値 ON）、「新規リスト追加」 |
| SC-06 の確定 | 完了ボタンでチェック状態をまとめて反映する（チェック操作の時点では保存しない） |

### SC-10 リスト / SC-11 リスト内の単語 / SC-12 保存単語 / SC-13 新規リスト作成

| 項目 | 定義 |
| --- | --- |
| SC-10 表示 | 「保存単語一覧」への入口、リストの一覧（登録単語数つき）、＋ボタン |
| SC-10 操作 | タップ → SC-11 / ＋ → SC-13 / 長押し →「名前の変更」「削除」「並び替え」 |
| SC-11 操作 | タップ → SC-03 / 長押し → 保存・チェック問題登録・並び替え・削除 / スワイプ → 削除 |
| SC-12 操作 | タップ → SC-03 / スワイプ → 確認のうえ削除 / 長押し → SC-05 |
| 入力チェック（リスト名） | 空白のみ不可:「リスト名を入力してください」/ 既存と重複不可:「同じ名前のリストが既にあります」/ 最大 30 文字 |

### SC-20 単語テスト / SC-21 テスト結果

| 項目 | 定義 |
| --- | --- |
| 出題 | 収録単語から無作為に 10 問。説明文を示し、単語名を 4 択で選ぶ |
| 解答時 | 正解を緑、誤答を赤で表示。不正解ならその単語のミス回数を +1。1 秒後に次の問題へ |
| 終了時 | インタースティシャル広告（間隔制限あり）の後、SC-21 へ置き換え遷移 |
| SC-21 表示 | 正解数 / 問題数、問題ごとの正誤・問題文・選択肢・ミス回数。選択肢をタップするとその単語の説明を表示 |
| SC-21 操作 | 「ホームに戻る」→ SC-01 / 「もう一度」→ リワード広告。報酬を得たら問題数 +10、得なければ同じ問題数で SC-20 |

### SC-22 単語チェック問題 / SC-23 単語チェック

| 項目 | 定義 |
| --- | --- |
| SC-22 表示 | 登録済みの単語の一覧、「問題出題」ボタン |
| SC-22 操作 | スワイプ → 確認のうえ登録解除 / 長押し → 保存・削除 / 「問題出題」→ SC-23 |
| SC-23 出題 | 登録済みの単語（収録単語に含まれるもの）から最大 10 問。誤答の選択肢は収録単語全体から選ぶ |
| メッセージ | 登録 0 件:「チェックされた問題がありません」 |
| 結果 | SC-21 を共用。「もう一度」は広告なしで SC-23 を再出題 |

### SC-24 仕訳問題設定

| 項目 | 定義 |
| --- | --- |
| 表示項目 | 出題範囲のチェックボックス 3 つ（簿記3級-商業簿記 / 簿記2級-商業簿記 / 簿記2級-工業簿記。初期値はすべて ON）、「問題出題」ボタン |
| 保存 | チェックを変えるたびに保存する |
| 入力チェック | 1 つも選ばないとボタンを押せず、「出題範囲を1つ以上選択してください。」を表示 |
| 遷移 | 「問題出題」→ SC-25 へ置き換え遷移 |

### SC-25 仕訳テスト / SC-29 電卓

| 項目 | 定義 |
| --- | --- |
| 出題 | 出題範囲に合う問題から無作為に 10 問 |
| 表示項目 | 問題番号 / 総数（種別）、問題文、借方・貸方の入力欄（正解の行数ぶん）、「回答を提出」、右上の問い合わせボタン |
| 入力欄 | 勘定科目はドロップダウン、金額は数値入力（3 桁区切りに自動整形）。金額欄の電卓ボタン → SC-29、計算結果を入力欄に反映 |
| 勘定科目の選択肢 | 正解の科目＋全問題の科目からの誤答候補で最低 10 件。コード順に並べる |
| 入力チェック | 未入力の行がある:「借方のすべての項目を入力してください」（貸方も同様）。採点しない |
| 採点 | 借方・貸方それぞれで、科目と金額の組が順不同で完全一致すれば正解 |
| 問い合わせ | 問題 ID をクリップボードにコピーし、Google フォームを開く |
| 終了時 | インタースティシャル広告の後、SC-26 へ置き換え遷移 |

### SC-26 仕訳テスト結果 / SC-27 仕訳問題一覧 / SC-28 仕訳問題詳細

| 項目 | 定義 |
| --- | --- |
| SC-26 表示 | 問題ごとの正誤・正解仕訳・解説 |
| SC-26 操作 | 問題から SC-28 / 「ホームに戻る」→ SC-01 / 「もう一度」→ リワード広告。報酬を得たら +5 問、得なければ同じ問題数で SC-25 |
| SC-27 | 全 270 問の一覧。タップ → SC-28 |
| SC-28 | タブ「問題内容」（SC-25 と同じ解答 UI）と「解説」（正解仕訳と解説文） |

### SC-30 スケジュール管理 / SC-31 スケジュール追加・編集

| 項目 | 定義 |
| --- | --- |
| SC-30 表示 | 受験日カード（今後の受験日を日付順に最大 3 件、「受験日まで N 日」）、タブ「カレンダー」「タスク一覧」、＋ボタン |
| カレンダー | 月表示。予定のある日に印。選んだ日の予定を下に表示 |
| タスク一覧 | 未完了を「過去 / 本日 / 未来」に分け、完了したものは「完了タスク」にまとめる |
| SC-30 操作 | ＋ / 予定をタップ / 受験日カード → SC-31 / 予定を長押し →「完了とする / 未完了に戻す」「タスクを削除」 |
| SC-31 入力項目 | 種別（勉強タスクを設定する / 受験日として設定する）、タイトル、詳細、開始日時、終了日時、タスク（カンマ区切り。勉強予定のみ） |
| SC-31 入力チェック | タイトル必須:「タイトルを入力してください」/ 勉強予定は終了が開始より後:「終了日時は開始日時より後にしてください」/ 受験日は今後の日付で 3 件まで: ダイアログ「受験日の設定制限」 |
| SC-31 削除 | 編集時のみ削除ボタン。「本当にこのスケジュールを削除しますか？」で確認 |

### SC-40 簿記ニュース / SC-41 記事閲覧

| 項目 | 定義 |
| --- | --- |
| SC-40 表示 | タブ「簿記３級」「簿記２級」「簿記１級」「会計関連」。各タブで Google ニュース RSS から取得した記事を無作為順に 15 件（タイトル・サムネイル） |
| SC-40 操作 | 引っ張って更新 / エラー時「再読み込み」/ 記事をタップ → インタースティシャル広告の後 SC-41 |
| SC-41 表示 | アプリ内 WebView。表示中のドメインをタイトル下に常時表示 |
| SC-41 制約 | `http` / `https` 以外の URL は開かない。カメラ・マイク・位置情報の要求は拒否 |
| SC-41 操作 | 「ブラウザで開く」→ 外部ブラウザ |

### SC-50 設定と配下の画面

| ID | 定義 |
| --- | --- |
| SC-50 | 「全般」「単語検索」「メモ一覧・単語一覧」「仕訳問題設定」「セキュリティとプライバシーポリシー」の区分で、配下の画面と SC-24・SC-27 へのリンクを並べる |
| SC-51 | ライト / ダーク / 端末の設定に従う、の選択と Material 3 の ON/OFF。即時に反映して保存 |
| SC-52 | 削除項目（検索履歴・ミス回数・リスト・保存単語一覧・単語チェック問題・自分で追加した単語・メモ一覧・スケジュール、「すべて削除」）を選ぶ。未選択:「削除する項目を選択してください」。確認「削除してよろしいですか？ この操作は取り消せません。」→ インタースティシャル広告 → 削除 → アプリを再起動 |
| SC-53 | SC-01 で詳細を開いた単語の履歴（新しい順、最大 15 件）。タップ → SC-03、全削除できる |
| SC-54 | メモを書いた単語の一覧。メモを個別に削除できる |
| SC-55 | 収録単語＋カスタム単語の一覧。分類で絞り込める。＋ → SC-56 |
| SC-56 | 単語（必須:「単語を入力してください」）・読みガナ（任意）・説明（任意）。追加後「「◯◯」を追加しました。」、同名がある場合「同じ名前の単語が既に登録されています。」 |
| SC-57 | 同梱の `assets/privacypolicy.txt` を表示 |
| SC-58 | フィードバック用の Google フォームを外部ブラウザで開く |
