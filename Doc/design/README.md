## 用語

| 用語 | 意味 |
| --- | --- |
| 単語（Product） | 簿記用語 1 件。名前・読みガナ・説明・分類を持つ。コード上のクラス名は `Product` |
| 収録単語 | アプリに同梱した `assets/products.json` の単語（1,373 語） |
| カスタム単語 | ユーザーが単語一覧画面から追加した単語 |
| マイリスト（Category） | ユーザーが作る単語のグループ。コード上のクラス名は `Category` |
| 保存単語 | マイリストとは別に、「保存単語一覧」に入れた単語 |
| チェック問題 | ユーザーが「単語チェック問題に登録」した単語。チェック問題テストの出題対象 |
| 仕訳問題（SortingProblem） | 取引文から借方・貸方の勘定科目と金額を答える問題（270 問） |
| 出題範囲フィルター | 仕訳問題を「簿記3級-商業簿記」のような「級-種別」単位で絞り込む設定 |
| 受験日 | スケジュールのうち `isExamDate = true` のもの。最大 3 件 |
